# FinSmart - Digital Banking System

FinSmart is a prototype digital banking system developed as part of an
Agile Software Development and DevOps project.

## Features

- Account Balance
- Transaction History
- Money Transfer
- Automated Testing
- CI/CD Pipeline

## Technologies

- Node.js
- Express.js
- Jest
- Supertest
- Git
- GitHub
- GitHub Actions

## Agile Connection

The project implements user stories and requirements defined in
Assignment 1.

## DevOps Pipeline

Code → GitHub → GitHub Actions → Build → Test → Deployment
